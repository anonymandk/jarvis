# F5 web UI evidence

Generated by [`scripts/capture_web_ui.py`](../../../../scripts/capture_web_ui.py) with Playwright Chromium, the local Next.js production server, and deterministic synthetic API/WebSocket fixtures. No Gemini credential or live service was used.

All seven client states and the reduced-motion preference were captured at 1440×900. The auth page was also captured in its initial loading state; onboarding uses the 420×640 compact viewport; the populated console uses the 980×680 minimum desktop viewport. `capture-metrics.json` records viewport and document dimensions and the capture script fails on horizontal overflow.
