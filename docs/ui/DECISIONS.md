# UI Decisions

Decisions made for the JARVIS UI mission. Dates use the repository's client timezone, America/Campo_Grande.

| Date | Decision | Reason |
|---|---|---|
| 2026-10-01 | Use both desktop and web scope, delivering desktop first. | The request's scope field is blank; this is the specified default and both surfaces are present in the repository. |
| 2026-10-01 | Use `SPEC`: PRODUCT.md controls product principles and anti-references; `docs/ui/figma-spec.md` controls layout, components, visible states, event mapping, and accessibility. | This resolves the document conflict according to the mission's default rule. |
| 2026-10-01 | Keep the Arc Reactor identity from DESIGN.md and use a single final token set in DESIGN.md plus `ui/theme/tokens.py`. Adjust individual colors when needed to meet WCAG AA; do not mix in the spec's separate palette. | Retains the existing visual identity while providing one source of runtime truth and measurable contrast. |
| 2026-10-01 | Keep bundled Space Grotesk for UI text and JetBrains Mono for technical data. Do not add Rajdhani, Orbitron, or Inter. | The repository already bundles the chosen families and their OFL licenses; no new font dependency is needed. |
| 2026-10-01 | Use solid, opaque panels and no decorative blur. Use a high-opacity dark fill only for the floating overlay, with fully opaque text and verified contrast. | Preserves the PRODUCT/DESIGN guidance against decorative glass while allowing the spec's overlay treatment. |
| 2026-10-01 | Replace the 80×80 compact dock with the spec's 420×640 compact conversation window; its return action restores the desktop workspace. | The compact entry point must expose conversation, status, recent activity, and input instead of an orb-only window. |
| 2026-10-01 | Label state with Portuguese text and an icon as well as color; show unavailable values as `—`, and label non-measured audio motion as “atividade”. | Color alone is insufficient; the current client does not emit RTT or audio amplitude and the product forbids fabricated telemetry. |
| 2026-10-01 | Keep JarvisLive, actions, hosted API, and prompt behavior unchanged. Translate only existing client calls/events in presentation adapters; document missing `tool_call`, structured `error`, `reconnecting`, RTT, and audio-level signals as follow-up requests. | Maintains the mission's engine/API boundary and prevents UI state from implying signals the backend does not provide. |
| 2026-10-01 | Honor OS reduced-motion preference and provide an explicit reduced-motion setting. Routine animation runs only for state/action transitions; the existing “low” graphics profile remains free of continuous animation. | Meets accessibility and legacy graphics-profile requirements without losing the reactor identity. |
| 2026-10-01 | Treat Linux as the available test host; do not claim Windows 11 or macOS verification without those systems. | The requested Windows 11 checks cannot be run in the current environment. |
| 2026-10-01 | Keep the Python full-suite CI job headless, install test tooling from `requirements-dev.txt`, and cache both runtime and development requirement manifests. | This makes the existing Qt regressions part of CI while keeping pytest out of the application runtime dependency list. |
| 2026-10-01 | Keep three manual graphics profiles and add `auto` as a separate device recommendation mode; manual selection overrides late automatic results. | This preserves existing low/medium/high controls while making the saved mode and hardware recommendation explicit. |
| 2026-10-01 | Keep the first-run narration in Gemini TTS, keyed by selected voice and intro version, and do not substitute an operating-system voice when rendering fails. | The selected voice remains consistent, the 90-second tour can reuse prepared audio, and setup/readiness does not imply success when audio is unavailable. |
| 2026-10-01 | Require the intro and its voice preparation to finish before the UI reports operational readiness; replaying the interface tour temporarily locks text input and pauses presence popups. | This prevents commands from reaching the engine while the onboarding surface is guiding the user through the console. |
| 2026-10-01 | Play the guided tour once, keep recurring startup greetings off for fresh settings, and preserve only an explicit legacy replay preference during migration. | Routine launches proceed directly to setup/console; audio failures release the interaction gate for recovery. |
| 2026-10-01 | Extract the existing Qt UI into responsibility-based `ui/` modules while keeping `import ui` and its patchable compatibility surface through `ui/__init__.py` and `ui/_runtime.py`. | Existing engine, awareness, probe, and test callers rely on the module API; F2 must reorganize presentation code without changing its visible result. |
| 2026-10-01 | Store the Arc Reactor palette and all legacy theme palettes in `ui/theme/tokens.py`; use that module as the single source for colors, typography, spacing, radii, and motion. Adjust text-role colors to pass WCAG AA contrast and keep existing numeric aliases during the staged refactor. | Central tokens prevent palette drift while preserving saved theme preferences and the current component geometry; semantic token scales define the values for new components. |
| 2026-10-01 | Translate only explicit `JarvisClient` state, log, and subtitle inputs into the versioned UI event envelope. Expose constructors for tool, metric, and structured error events only when callers have those facts. | The current engine does not emit structured tool calls, measured RTT/audio levels, or recoverability metadata, so deriving them from logs or animation would misstate runtime data. |
| 2026-10-01 | Keep font families, platform fallbacks, and legacy family aliases in `ui/theme/tokens.py`; existing widgets use the resolved body/mono roles. | This completes typography centralization while preserving native fallback behavior and the bundled Space Grotesk/JetBrains Mono fonts. |
| 2026-10-01 | Validate text-role contrast against all declared panel, state-card, and hover surfaces, plus the warning-toast and primary-button foreground/background pairs. | Checking only the base background missed low-contrast combinations on actual cards and bars, especially in the platinum theme. |
| 2026-10-01 | Assign a stable generated `turn_id` to each mapped transcript turn and synchronize event sequence/turn updates. | Consumers need to group partial/final transcript messages correctly, and the event mapper must remain ordered for concurrent producers. |
| 2026-10-01 | Preserve the existing file-category icon hues as a separate token family instead of replacing them with generic semantic colors. | Token centralization must not change the established file-type visual mapping during the F3 refactor. |
| 2026-10-01 | Move voice metadata to `core/voice_catalog.py` and inject first-run audio renderers through the UI facade. | UI presentation modules must not import `actions/` or vendor SDKs; the host owns Gemini integration while the existing voice data and narration behavior stay the same. |
| 2026-10-01 | Keep alpha values in named opacity tokens and combine them with semantic theme colors through `qss_rgba`. | Numeric RGB/RGBA literals bypass theme palettes and make opacity styling drift across screens. |
| 2026-10-01 | Use a theme-aware dark foreground for warning-toast text and controls on the amber surface. | White or dim text on `ACC2` fell below AA in every palette; the warning text pair now stays above 4.5:1 without changing the amber warning background. |
| 2026-10-01 | Keep letter spacing and Qt easing names in the token registry alongside sizes and durations. | The last literal spacing value and direct easing enum choices bypassed the F3 single-source rule. |
| 2026-10-02 | Use shared layout tokens for the 1440×900 reference frame, 980×680 minimum desktop frame, 72 px navigation rail, 317 px transcript/execution panels, and 420×640 compact window. | A central geometry contract keeps the 12/6/3 composition stable while the splitter adapts to the available viewport. |
| 2026-10-02 | Render measured connection latency as `—` when unavailable and label the orb waveform as activity rather than audio amplitude. | The current client does not publish RTT or audio-level events; showing a fabricated value would mislead users. |
| 2026-10-02 | Preserve low/medium/high graphics modes and add persisted system/reduced/full motion preference; the low profile disables continuous motion. | Users retain their existing graphics choices while receiving an explicit motion setting that honors OS reduced-motion where detected. |
| 2026-10-02 | Add accessible names and visible focus to navigation, compact controls, settings, and custom graphics choices; keep interactive targets at least 40×40 px and log text at least 12 px. | These are measurable requirements in the desktop spec and apply to keyboard, screen-reader, and compact-window use. |
| 2026-10-02 | Capture desktop, compact, settings, state, graphics, and reduced-motion surfaces with an offscreen Qt probe; mark synthetic connection states as test fixtures. | This host can verify rendering deterministically, but it has no live Gemini session or Windows/macOS display environment. |
| 2026-10-02 | When the client reports an error without structured details, state only that an error was signaled and direct the operator to Logs before retrying. | The UI can offer a useful next step without inventing a cause or changing the client contract. |
| 2026-10-02 | Promote `design/tokens.json` to the shared token source; generate the Python runtime tokens and web CSS from it and check both generated files for drift. | Desktop and web now consume the same palette, typography, spacing, radius, motion, and layout values without hand-maintained copies. |
| 2026-10-02 | Adapt only websocket event types already sent by the current web client to the v1 UI envelope; accept explicit v1 envelopes and keep missing telemetry as `—`. | The browser can use the shared presentation contract without changing the API or implying unsupported tool calls, RTT, audio levels, or error recovery. |
| 2026-10-02 | Re-key the reactor when its visible state changes, let the CSS reduced-motion media rule disable its finite transition, and use automatic conversation scrolling under the same preference. | State changes get a bounded visual response and incoming messages do not request smooth scrolling when reduced motion is enabled. |
| 2026-10-02 | Ignore message, error, and close callbacks from superseded websocket instances. | React development Strict Mode can close an initial connection while a replacement is opening; an old close must not mark the live connection as reconnecting. |
| 2026-10-02 | Capture web states with Playwright against deterministic synthetic API and websocket fixtures; label that evidence as simulated. | Layout and event adaptation can be verified without credentials or a live Gemini session, while avoiding claims about production-service behavior. |
| 2026-10-02 | Point the README clone command to `anonymandk/jarvis`, the repository being maintained by this mission. | The old command sent contributors to the separate `MAL19INDUSTRIES/JARVIS-OS-V.2` repository. |
| 2026-10-02 | Keep `PRODUCT.md` unchanged and rewrite `DESIGN.md` to describe the implemented shared token source, desktop/web composition, accessibility, and telemetry limits. | Product principles remain authoritative; implementation details and current UI constraints belong in the design handoff. |
| 2026-10-02 | Link the README to committed F4 desktop and F5 web screenshot evidence and identify fixture-generated states as synthetic. | Contributors can inspect both interfaces without mistaking test data for a live Gemini or hosted session. |

## Still to verify during implementation

- Windows 11 and macOS behavior, OS-level reduced-motion detection on each desktop environment, high-DPI scaling, and secondary displays.
- Live microphone/audio synchronization, Gemini reconnect behavior, measured RTT, and tool-call status after the client exposes those events.
- User-owned settings migration under real pre-existing `~/.jarvis/config` files on each supported OS.
- Human visual and keyboard review on the target Windows 11 device; the automated evidence here is offscreen Linux Qt.
