## Limits and remaining work

- The host is Linux with offscreen Qt. Windows 11, macOS, high-DPI scaling, secondary displays, and a human keyboard/screen-reader pass on the target device remain unverified.
- Session-state screenshots use deterministic QA fixtures. There is no live Gemini session in this run. The current client does not publish reconnect events, structured errors, tool-call progress, measured RTT, or audio amplitude; unavailable values remain `—` or “atividade”.
- UI settings and API-key paths in the probe are redirected to temporary files. The test suite checks preference preservation, but this run did not migrate real user files on each supported operating system.
- The automated report still records two repository-level follow-ups for F6: 471 broad `Exception` handlers and legacy `google.generativeai` imports in nine runtime modules. Neither finding is a failed F4 check.
- The BlackPearl DSH pipeline launcher remains unavailable on this Linux install due to its BOM and Windows-only paths, as recorded in [the architecture report](../ARCHITECTURE.md). The local BlackPearl UI designer and finish-gate guidance was used; the independent finish-gate reviewer passed cycle 3 with no blockers.
